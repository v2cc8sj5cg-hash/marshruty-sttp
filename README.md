# Маршруты СТТП — стартовый каркас

## Запуск
Откройте папку через локальный веб-сервер (не через file://). Например:
`python3 -m http.server 8000`
Затем откройте `http://localhost:8000`.

## Что уже работает
- Карта Санкт-Петербурга на OpenStreetMap / Leaflet.
- Переключение независимых слоёв: маршруты, контактная сеть, элементы сети, остановки.
- Поиск и выбор маршрута в каталоге.
- Карточка объекта по нажатию.
- PWA manifest и service worker для кэширования оболочки.

## Структура данных
Все пространственные данные — GeoJSON:
- `data/routes.geojson` — трассы маршрутов. Для каждого направления лучше хранить отдельный Feature.
- `data/contact-network.geojson` — геометрия проводов. Рекомендуемые свойства: `id`, `status`, `voltage_section`, `notes`, `source`, `verified_at`.
- `data/network-elements.geojson` — точечные элементы. `type`: `switch`, `crossing`, `insulator`, `junction`, `loop`.
- `data/stops.geojson` — остановки и конечные.

## Важно
Слои оставлены пустыми намеренно: приложение не подменяет проверенные геоданные выдуманными трассами или расположением проводов. Официальные описания маршрутов — исходный справочник, но контактную сеть и точную геометрию необходимо отдельно оцифровывать и проверять.
Карта OSM загружается из внешнего тайлового сервиса, поэтому сама подложка не гарантированно доступна офлайн.
